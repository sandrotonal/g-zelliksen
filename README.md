# Güzellik Salonu

Modern ve şık güzellik salonu web sitesi.

## Özellikler

- Responsive tasarım (mobil uyumlu)
- Hero slider
- Hizmetler bölümü
- Galeri
- Müşteri yorumları
- Randevu formu
- İletişim bilgileri

## Teknolojiler

- HTML5
- CSS3 (Tailwind CSS)
- JavaScript
- Lucide Icons
- Unsplash görselleri
