# Rose Beauty Studio

Istanbul-based premium beauty studio website. Features a modern, elegant design showcasing 16 beauty services with interactive gallery and appointment booking.

## Features

- Responsive design (mobile-first, works on all devices)
- Hero slider with 7 rotating slides
- 16 service cards with tilt effect and grayscale-to-color hover
- Horizontal scrollable service section
- Marquee ticker for service names
- Image gallery (Visual Journey) with grayscale hover effect
- Customer reviews section
- Appointment form
- Contact information with WhatsApp integration
- Mobile hamburger menu
- Smooth scroll navigation
- Intersection Observer scroll animations
- Privacy policy, terms, and KVKK pages

## Technologies

- HTML5
- CSS3 with Tailwind CSS (via CDN)
- Vanilla JavaScript
- Lucide Icons (via CDN)
- Google Fonts (Syne, Plus Jakarta Sans)
- Images from Unsplash and Pexels
